# あといくら — iPhone用 Ver.1

使いすぎ防止を目的にした、自分専用のお小遣い帳PWAです。

## 入っている機能
- 月に使っていい金額を設定
- 今月の手取りを設定
- 月初の貯金残高を設定
- 支出を「金額 / 内容 / カテゴリー / 日付」で登録
- 今月あと使える金額
- 予算消化率
- 支出ペース判定
- 月末の支出予測
- 残り日数から1日あたり使える目安を計算
- 推定の全財産と、全財産に対する今月支出率
- 支出削除
- JSONバックアップ書き出し / 読み込み
- IndexedDBによる端末内保存
- Service Workerによるオフライン利用

## iPhoneに入れるために
PWAはHTTPS上で開く必要があります。
このフォルダの中身を GitHub Pages / Netlify / Cloudflare Pages などの静的ホスティングに置き、
iPhoneのSafariでURLを開きます。

Safari → 共有 → ホーム画面に追加 → 「Webアプリとして開く」をオン → 追加

## お金全体の計算
推定全財産 = 月初の貯金残高 + 今月の手取り - 今月の支出

「月初の貯金残高」は、今月の手取りが振り込まれる前の金額を想定しています。
これにより手取りの二重計上を避けます。

## 注意
データは基本的にiPhone内のWebアプリ領域に保存されます。
SafariのWebサイトデータ削除や端末トラブルに備え、設定画面から時々バックアップを書き出してください。
