# @ikura — iPhone用 Ver.2

使いすぎ防止を目的にした、自分専用のお小遣い帳PWAです。

## Ver.2の変更
- 家計の1期間を「毎月25日〜翌月24日」に変更
- ホームに現在の期間（例: 8/25〜9/24）を表示
- 服・外食など、カテゴリーごとの予算を設定可能
- カテゴリーごとに「@ikura」を表示
- 支出登録前に、全体予算とカテゴリー予算の両方について登録後の残額を確認可能
- 「外食」カテゴリーを追加
- Ver.1の現在月設定を、初回起動時に現在の25日始まり期間へ自動引き継ぎ
- Service Workerキャッシュをv2へ更新

## カテゴリー
- 食費
- 外食
- 服
- 交際費
- 趣味
- 交通
- 日用品
- その他

カテゴリー予算は0円の場合「未設定」として扱います。

## データ保存
支出・予算などはIndexedDBでiPhone内に保存します。GitHubには家計データは保存されません。

## お金全体の計算
推定全財産 = 期間開始時の貯金残高 + 今回の手取り - この期間の支出

「期間開始時の貯金残高」は25日の給料振込前の金額を想定しています。

## バックアップ
設定画面からJSONを書き出し・読み込みできます。Safariのデータ削除や機種変更に備え、ときどき書き出してください。
